数据来源说明

本页面所有数据均来自公开可访问的来源，包括各模型厂商的官方发布页、官方 API 定价页与官方文档， 以及 Artificial Analysis、LMArena 等公开榜单的原始页面。每条记录在详情弹窗中列出其来源链接与采集日期。

未找到可靠来源的字段一律填 null 并在页面上显示为「暂无数据」，不做估算，也不引用未经核实的二手数据。 页面显示的数值为采集时点的快照，可能与当前实际值存在差异。
