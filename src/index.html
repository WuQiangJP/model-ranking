データ出典について

本ページのデータはすべて公開されたアクセス可能なソースに基づく。対象は各モデルのベンダーによる 公式発表ページ、公式 API 価格ページ、公式ドキュメント、および Artificial Analysis や LMArena などの 公開ランキングの原ページ。各レコードの出典リンクと取得日は詳細モーダルに記載する。

信頼できるソースが見つからなかった項目は null とし、ページ上では「データなし」と表示する。 推定は行わず、未確認の二次情報も引用しない。表示される数値は取得時点のスナップショットであり、 現在の実際の値と異なる場合がある。

生データをダウンロード（data/models.json） · データ検証ルールを見る（data/schema.json） · ベンチマーク定義を見る（data/benchmarks.json）

本サイトは完全な静的サイトであり、訪問者の情報を収集せず、Cookie を設定しない。
